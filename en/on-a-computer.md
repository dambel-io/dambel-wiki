# Using Dambel on a computer

Dambel is the same app in a browser as it is on a phone — same account, same data, same everything. What changes is the shape it takes when it has room.

Open **app.dambel.io** and sign in.

---

## The layout on a wide window

Dambel watches the width of the window rather than the kind of device, so a browser tab dragged narrow behaves like a phone and a phone in landscape can behave like a tablet.

| Window | What you get |
|---|---|
| **Narrow** | The phone layout: four tabs along the bottom |
| **Medium and wider** | The four move to a **rail down the side**, and the chat, notifications and assistant icons move to the foot of that rail |
| **Wide** | The rail carries labels beside its icons |

Content does not stretch to fill a very wide window — it is held to a comfortable reading width in the middle, so a form does not become a line of text a metre across. Lists and detail screens use the extra room by sitting side by side instead: a list on one side, what you picked on the other.

The [AI assistant](ai-assistant.md) follows the same rule. On a phone it covers the screen; here it docks beside what you were reading, so you can keep both in view.

---

## Using the keyboard

Every control can be reached by **Tab**, and whatever has focus is outlined so you can see where you are. **Enter** or **Space** activates it. **Esc** closes whatever is open — a panel, a sheet, a dialog — before it means anything else.

Forms are wired for the keyboard end to end: **Enter** moves to the next field and submits from the last one, and your browser's saved phone number and password are offered where you would expect them.

---

## Installing it

Dambel can be installed so it opens in its own window, without browser chrome, and sits with your other apps.

| Where | How |
|---|---|
| **Android (Chrome)** | Chrome offers to install it; accept the prompt, or use **⋮ → Install app** |
| **Desktop (Chrome, Edge)** | The install icon at the end of the address bar, or **⋮ → Cast, save and share → Install** |
| **iPhone / iPad (Safari)** | The **Share** button, then **Add to Home Screen**. This is how Dambel is installed on an iPhone — there is no App Store download |

An installed Dambel updates itself; there is nothing to reinstall when a new version ships.

---

## When you are offline

If you open Dambel with no connection, you get a Dambel page saying so — in your language — rather than the browser's own error. It stays there and lets you try again once you are back.

Inside the app, anything that needed the network says so on the screen it failed on, with a way to retry.
